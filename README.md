# Простейший поисковый робот

## Описание

Это учебная программа для простого обхода сайта. Она начинает с указанного URL, загружает страницы, собирает найденные ссылки и сохраняет небольшую статистику по результатам.

## Что использовалось

- Python
- requests
- BeautifulSoup4
- pytest

## Как установить

```bash
python -m venv .venv
```

Для Windows:

```bat
.venv\Scripts\activate
```

Для macOS/Linux:

```bash
source .venv/bin/activate
```

После активации окружения:

```bash
pip install -r requirements.txt
```

## Как запустить

```bash
python main.py --url https://example.com --max-pages 10 --max-depth 1 --delay 0.5
```

Параметры:

- `--url` — начальный сайт;
- `--max-pages` — сколько страниц максимум обработать;
- `--max-depth` — глубина переходов по ссылкам;
- `--delay` — задержка между запросами;
- `--output-dir` — папка для сохранения результатов.

Пример с указанием папки:

```bash
python main.py --url https://example.com --max-pages 10 --max-depth 1 --delay 0.5 --output-dir data
```

## Что сохраняется

После запуска в папке `data/` появляются файлы:

- `pages.json` — данные по обработанным страницам;
- `pages.csv` — то же самое в табличном формате;
- `report.json` — общая статистика.

## Как запустить тесты

```bash
pytest
```

Тесты проверяют работу с URL, парсер HTML, обход страниц и формирование отчёта. Реальные запросы в тестах не выполняются.

## Ограничения

- робот сделан в учебных целях;
- он не предназначен для обхода больших сайтов;
- часть сайтов может блокировать запросы;
- желательно не ставить слишком маленькую задержку.
