# Простейший поисковый робот

## Описание

Это учебная программа для простого обхода сайта СПбГУ. Робот начинает с указанного URL, загружает страницы, собирает ссылки, извлекает заголовок и очищенный текст страницы, а затем сохраняет результаты и статистику.

## Что использовалось

- Python
- requests
- BeautifulSoup4
- pytest

## Как установить

```bash
python -m venv .venv
```

Для Windows:

```bat
.venv\Scripts\activate
```

Для macOS/Linux:

```bash
source .venv/bin/activate
```

После активации окружения:

```bash
pip install -r requirements.txt
```

## Как запустить

```bash
python main.py --url https://spbu.ru --max-pages 10 --max-depth 1 --delay 0.5 --output-dir data/spbu_10
```

Параметры:

- `--url` - начальный сайт;
- `--max-pages` - сколько страниц максимум обработать;
- `--max-depth` - глубина переходов по ссылкам;
- `--delay` - задержка между запросами;
- `--output-dir` - папка для сохранения результатов.

## Что сохраняется

После запуска в папке, указанной через `--output-dir`, появляются файлы:

- `pages.json` - данные по обработанным страницам;
- `pages.csv` - те же данные в табличном формате;
- `report.json` - общая статистика.

Для каждой страницы сохраняются URL, статус ответа, заголовок, глубина обхода, очищенный текст, внутренние и внешние ссылки, а также ошибка, если страница не загрузилась.

## Как запустить тесты

```bash
python -m pytest
```

Тесты проверяют работу с URL, парсер HTML, обход страниц, извлечение текста и формирование отчёта.

## Тестирование производительности и результаты

Benchmark запускается командой:

```bash
python benchmark.py
```

Он выполняет небольшие проверки на сайте СПбГУ с разными ограничениями по количеству страниц и глубине обхода. Результаты сохраняются в:

- `data/benchmark/benchmark_results.csv`
- `data/benchmark/benchmark_results.json`
- `data/benchmark/benchmark_report.md`

Для отдельной большой проверки был выполнен запуск:

```bash
python main.py --url https://spbu.ru --max-pages 5000 --max-depth 2 --delay 0.5 --output-dir data/spbu_5000
```

Результаты сохранены в:

- `data/spbu_5000/pages.json`
- `data/spbu_5000/pages.csv`
- `data/spbu_5000/report.json`

При `max_depth=2` робот обработал 2161 страницу, потому что очередь найденных внутренних ссылок закончилась раньше лимита `max_pages=5000`.

## Ограничения

- робот сделан в учебных целях;
- он не предназначен для агрессивного обхода больших сайтов;
- часть сайтов может блокировать запросы;
- желательно не ставить слишком маленькую задержку между запросами.

## Данные для третьего модуля

Данные обхода сохраняются в `pages.json`. Для построения инвертированного индекса используется поле `text` - очищенный текст страницы.

Перед модулем 3 можно подготовить отдельный JSONL-файл документов:

```bash
python prepare_module3_data.py --input data/spbu/pages.json --output data/module3/spbu_documents.jsonl
```

Для маленькой проверки можно использовать:

```bash
python prepare_module3_data.py --input data/spbu/pages.json --output data/module3/spbu_documents_small.jsonl --limit 10
```

В результат попадают только успешно загруженные страницы с `status_code == 200`, без ошибки и с непустым `text`.
