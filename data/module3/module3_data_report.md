# Данные для третьего модуля

## Назначение

Эти файлы подготовлены для третьего модуля, где нужно строить инвертированный индекс по страницам, собранным поисковым роботом.

## Источники данных

| Сайт | Исходный файл pages.json | Подготовленный файл JSONL | Количество документов | Общий объем текста |
|---|---|---|---:|---:|
| СПбГУ | `data/spbu/pages.json` | `data/module3/spbu_documents.jsonl` | 50 | 559357 |

## Формат документа

Одна строка JSONL выглядит так:

```json
{"doc_id": 1, "url": "...", "title": "...", "text": "..."}
```

## Как использовать в третьем модуле

1. Открыть нужный файл JSONL.
2. Читать документы построчно.
3. Токенизировать поле `text`.
4. Построить инвертированный индекс.
5. Для поиска по запросу "Ректор СПбГУ" использовать тот же процесс токенизации.
